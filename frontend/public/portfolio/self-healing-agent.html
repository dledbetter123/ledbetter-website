Self-Healing Coding Agent

David's flagship project at Apple, on Release Validation, where he is lead researcher and engineer: a self-healing coding agent built around a world model that treats screens and the transitions between them as a sandbox to explore. The agent lives in a gym where writing code is its lever toward healing the automation engineering team’s test plans. David's in-house harness performs the repair and treats the model as a swappable reasoning engine; running it with Claude as the reasoning engine built the corpus for instruction fine-tuning (IFT) Gemma 4, which now runs the agent on its own.

What the agent does

  • Explores a world model. David developed a world model that treats screens and the transitions between them as a sandbox to explore; the agent lives in a gym where writing code is its lever toward healing the automation engineering team’s test plans.
  • Repairs code through David's harness. He designed the in-house harness, modeled after LangGraph, that performs the repair, treating the model as a swappable reasoning engine with a local Gemma 4 as the tool caller.
  • Repairs its plan online. The agent ingests the parsed, assembled form of the compiled Swift code to build a control-flow prior, is taught to measure incoming automation for deviations from that prior, and heals them.
  • Explores code as a partially observable Markov decision process (POMDP), so the agent acts on true divergences and ignores false error reports.
  • Reads through a RAG pipeline. Gemma 4 summarizes vision results and execution-flow traces into Claude's context.
  • Gets its measurements from an async Python probe manager that runs outside the agent and delivers consistent raw metrics into the agent flow without adding latency.
  • Learned from its own heals. David built a corpus by running the harness with Claude as the reasoning engine, which let him perform instruction fine-tuning (IFT) of Gemma 4 on online plan repair on a Mac Studio. The fine-tuned Gemma 4 now runs the agent on its own in place of Claude; it is deployed in the lab and saves $15,000 a month in token spend.
  • Reports to a dashboard David built, which monitors the agent's runs across the device gym. Opened to the greater QA org, it lets teams schedule jobs and keep up with their automation, saving 3–6 hours per person, per day, across the organization.
  • Runs alongside a fleet. David owned the deployment of a fleet of autonomous AI agents on an internal server spread across 3 Macs: the 3 Mac Studios act as ML-capable operators over a virtual distributed computing environment where tests run on deployed VMs that act as test devices and can talk to each other. He also built a local load-balancing cluster of lightweight agents serving LLM capabilities across applications.

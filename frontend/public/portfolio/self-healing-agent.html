Self-Healing Automation

Releases can ship several times a day, and each build’s UI issues and OS quirks break the automation team’s test code. David’s flagship project at Apple, on Release Validation, where he leads research and engineering, is a dynamic system through which those test plans heal themselves, so engineers are freed up for other problems. It is built around a world model that treats screens and the transitions between them as a sandbox to explore.

The test infrastructure around it

1,000s of hourssaved for the QA and automation teams by rewriting the automation backend, July–October 2025
10,000s of runsunblocked by an API asset randomization and pooling system that eliminated asset collisions
Splunkqueries implemented and automated in the backend, on an upgraded PostgreSQL model with SQLAlchemy/Pydantic endpoints for a Swift frontend

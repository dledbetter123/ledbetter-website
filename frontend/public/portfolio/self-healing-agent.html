Self-Healing Coding Agent

David's flagship project at Apple, on Release Validation: an agent that repairs code on its own. Claude does the repair reasoning, a local Gemma 4 model handles tool calls to cut token cost, and an in-house harness and task queue run it all.

What the agent does

  • Repairs code on its own. Claude auto-repairs code inside a custom in-house harness modeled after LangGraph, while a local Gemma 4 model performs the tool calling to cut token cost.
  • Repairs its plan online. The agent ingests the parsed, assembled form of the compiled Swift code to build a control-flow prior, is taught to measure incoming automation for deviations from that prior, and heals them.
  • Explores code as a partially observable Markov decision process (POMDP), so the agent acts on true divergences and ignores false error reports.
  • Reads through a RAG pipeline. Gemma 4 summarizes vision results and execution-flow traces into Claude's context.
  • Gets its measurements from an async Python probe manager that runs outside the agent and delivers consistent raw metrics into the agent flow without adding latency.
  • Learned from its own heals. David built a training corpus from heals run by the harness and distilled Claude's performance into Gemma 4. The distilled model is deployed in the lab and saves $15,000 a month in token spend.
  • Reports to a dashboard David built, which monitors the agent's runs across the device gym. Opened to the wider org, it lets teams schedule jobs and keep up with their automation, saving 3–6 hours per person.
  • Runs alongside a fleet. David owned the deployment of a fleet of autonomous AI agents on an internal server spread across 3 Macs, and built a local load-balancing cluster of lightweight agents serving LLM capabilities across applications.

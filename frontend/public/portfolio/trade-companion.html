Personal project · 2022–2024

Algorithmic Trading Companion

A stock-forecasting app: a model trained on Apple's daily closing prices, a Flask API that rolls a forecast forward 30 days, and a React page that charts it. The public repo holds that version, built on a stacked LSTM in Keras. David's CV describes the project as a hybrid transformer in PyTorch that adds news-headline sentiment, served through Flask/FastAPI and Go REST APIs on AWS and backtested in R.

What the repo does

Model · Stock.ipynb

A stacked LSTM on closing prices

Loads AAPL.csv, scales the closing price to the range 0 to 1, and splits the series 70/30 in time order: 880 days to train, 378 to test. Sliding 200-day windows give 679 training and 177 test examples. Three LSTM layers of 50 units feed a single output, trained with mean squared error and Adam for 100 epochs at batch size 64, on TensorFlow 2.10. The trained model is saved for the API.

API · base.py

Flask route that forecasts

The /predict route downloads the last 1,200 days of AAPL prices from Yahoo Finance with yfinance, fits a scaler, loads the saved model with joblib, and runs a rolling forecast. It returns JSON with the past closes, the forecast and both date axes. CORS is open so the front end can call it.

UI · App.js

React chart

A Display Prediction button calls /predict through axios and the create-react-app proxy to Flask on port 5000. A Plotly line chart draws the history in red and the forecast in green on a black background.

The project on David's CV

David's CV and LedbetterLM's project notes describe more than the public repo contains. The transformer, the sentiment model, the Go API and the R backtests are not in the repo, so this page shows none of their code or numbers.

Model

Hybrid transformer with headline sentiment

Price time series and news-headline sentiment combined in a hybrid transformer built with PyTorch and NumPy, using a specialized encoding scheme to interpret market behavior and headlines.

Horizon

30- and 90-day movement

The CV gives the forecast horizons as 30 and 90 days, the same default and cap as the forecast function in the repo's API.

Serving

Flask/FastAPI and Go REST APIs

Predictions served as JSON to a React UI on AWS. The project notes add model hosting on SageMaker with EC2 and Docker, and scheduled API calls that keep market data current.

Evaluation

Backtested in R

Both the CV and the project notes list backtesting in R.

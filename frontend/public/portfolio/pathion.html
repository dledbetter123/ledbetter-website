Pathion · pathion.dev · 2025–present

Pathion

A browser-native platform that helps students and engineers strengthen their interview readiness and learn engineering concepts, with every program running on-device in WebAssembly. As a developer there, David built the AI layer: an in-browser LLM tutor over WebNN and WebGPU, a hint model trained with SFT and RL, and the learning-data pipeline behind an adaptive Elo that rates skill from every attempt.

Pathion (formerly LILO) runs every program on the student's own device at zero marginal cost, and has 1,500 users.

What David owns

Model training

Distillation and an RLVR campaign that trained the tutor's hint model, measured by placebo-subtracted reader lift with paired-bootstrap confidence intervals.

On-device inference

The in-browser tutor: quantized Qwen over WebNN/WebGPU in a non-blocking Web Worker, with OPFS model caching, SHA-256 integrity checks and a Go service issuing versioned model manifests.

The telemetry spine that compiles each session into one Session Artifact, and the adaptive Elo that rates skill from it.

The cloud lane

AI cost is tiered by device. Work too heavy to run locally is hedged onto Cloudflare Workers AI against a Gemini warm-start, and the first valid response wins. David moved the hint model to a ~16× cheaper model and put the narrative lane (Llama 4 Scout) in production.

  • Built the telemetry spine: a client event taxonomy collapses each session into a canonical Session Artifact, which drives an adaptive Elo.
  • Designed Pathion's Record data model: one typed envelope (event, log, error, audit) instrumenting every facet of user interaction across 7 once-unjoinable client pipelines and the backend logs, so issues surface before a bug is filed.
  • Found production Elo frozen at 1200 for 227 of 228 active users, caused by email-keyed writes with no upsert, and fixed it with userId-keyed ratings. Then closed rating-farming holes, verified by the property and concurrency tests above.
  • Built Elo replay and repair tooling: deterministic replay, a byte-identical backup and restore rehearsal, and compare-and-swap gated apply.
  • Designed Glicko-1 confidence against a production backtest, and built a placement warm-up of 18 animated puzzles.
  • Built a production data heartbeat whose first run caught a dark rating table, and later found and fixed production action logs that had gone dark for two months.

Platform and infrastructure

  • Owns a 32,000-line Go backend on AWS Lambda behind API Gateway, with SQS workers, a DynamoDB rate limiter and MongoDB.
  • Led the monorepo and serverless migration off App Runner (prod, June 2026) for a ~95% hosting cut, and rebuilt staging as an idempotent mirror of prod.
  • Added ETag/304 caching and cursor pagination to read routes after staging replay moved 9.5 GB in 3 days, and made end-to-end CI hermetic with its own Go backend and Mongo container.
  • Deployed the Python TA hint service on Lambda to production in October 2026, with GitHub Actions deploys.
  • Built self-hosted CI on a company workstation while GitHub-hosted Actions were blocked: five Docker-in-Docker runners under an admission controller, running the full frontend gate green in ~30–35 min. Root-caused two silent hangs along the way: an MTU mismatch and stale runner sessions.
  • Built path-specific CI: each push runs only the test suites tied to the files it changes, so every deploy is gated on what its feature needs, with a flagged deploy-now path. Prod deploys went from 22–70 min to ~5.
  • Built eng.pathion.dev, the company engineering-directives site (S3, CloudFront, Lambda, DynamoDB), rebuilt hourly from Jira with comment threads and gated by Cloudflare Access. Also runs the company file server and WireGuard VPN.

Security, privacy and product

  • Built FERPA de-identification at the AI egress boundary (a field allow-list rebuild, comment scrubbing and a hard-off switch), in production, and closed an anonymous-access hole in the narrative fallback.
  • Owns the identity and authorization layer: Supabase-issued JWTs verified in Echo middleware with HS256 pinned to close an algorithm-confusion bypass, and RBAC on admin actions behind a deny-by-default gate on every route.
  • Shipped the student Ask the TA panel to production, with interactive hints (3 per attempt, ~$0.01 per attempt) and Java hints.
  • Built a timed interview mode (33 company profiles over 1,044 gradable problems) and a Big-O analyzer that times code in the browser with Pyodide and fits curves to the timings.
  • Fixed a judge bug where one failing hidden test failed every test after it, which had overstated 151 of 221 project verdicts. Also restored student code from the server and fixed an autosave data-loss bug.

Character-Aware Neural Language Model

A language model that reads every word through its spelling. David built it in PyTorch after Kim et al. (2016): a character embedding, a convolutional network over the characters and a highway network turn each word into a vector, and an LSTM predicts the next word. The model achieved a 3% reduction in perplexity against models of the same size.

Small by design

A word-level language model keeps a learned vector for every word it knows. This model keeps none on its input side. It computes each word's vector from the word's characters, using 50 character vectors, 256 convolution filters and two highway layers. That whole stage is 310,726 parameters. A lookup table of 256-number vectors for the same 9,999 words would need 2,559,744.

Character side (embedding, Char-CNN, highway) 310,726
Word lookup table, 256 wide, for the same 9,999 words 2,559,744
  • Rare and unseen words still get a vector, built by the same weights as every other word. The project README names out-of-vocabulary and rare words as the target.
  • Filters respond to substrings, so words that share a stem or an ending produce related features. The README frames this as a way to capture morphology.
  • Most of the remaining weight sits in the LSTM and the word softmax: 8,807,695 of the 9,118,421 parameters.

How each stage works

1 · Embedding

Characters to vectors

Each word becomes a row of up to 50 character IDs, padded with a reserved pad symbol. The alphabet has 50 symbols: the 48 characters in the training text plus pad and unknown. Each symbol maps to a learned 50-number vector, initialized uniformly between −0.1 and 0.1.

2 · Char-CNN

Filters over spelling

Four banks of filters slide across the character vectors, 2, 3, 4 and 5 characters wide, with 64 filters per bank and a tanh on each output. The paper's Figure 1 example uses widths two to four; David added width five.

3 · Max over time

One vector per word

Each filter keeps only its strongest response anywhere in the word, so the word's vector has a fixed size whatever the word's length: 4 × 64 = 256 numbers.

4 · Highway

Gated mixing

Two layers. Each computes a gate t from its input and outputs t · relu(WHx) + (1 − t) · x, choosing per value between transforming the input and carrying it through. A learned bias that starts at −2 tilts each gate toward carry at the start of training.

5 · LSTM

Sequence model

Two LSTM layers with 512 hidden units, with dropout of 0.1 between the layers and on the output.

6 · Softmax

Next-word scores

A linear layer maps the 512 hidden units to a score for each of the 9,999 words. Training minimizes cross-entropy against the word that actually came next.

From the paper to the code

Based on

Kim et al. (2016)

Character-Aware Neural Language Models, by Yoon Kim, Yacine Jernite, David Sontag and Alexander Rush, AAAI 2016. The same pipeline: character CNN, highway network, LSTM, softmax over words.

Hardest part

The highway network

David's design write-up names the highway network as one of the primary challenges: it has to draw character-level features out of a word while keeping the important information. The design answers with transform and carry gates.

Changed

A fifth filter width

The notebook follows the paper's figure for filter widths two to four and adds width five, with 64 filters at every width.

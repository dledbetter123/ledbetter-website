NSBE Chapter Website

The website for the UMBC chapter of the National Society of Black Engineers. Members sign up with a profile, a headshot and a resume, and the site shows them in a searchable carousel. David built the React front end, a Go backend on AWS Elastic Beanstalk with MongoDB, and direct-to-S3 uploads, while serving as the chapter's Finance Chair and Outreach Planner.

What David built

Back end · main.go

Go server

A Go 1.19 net/http server with four routes: a status page, /members/list, /members/newmember and /generateurl. It reads the MongoDB URI from the environment, stores members in the nsbemembers database, and signs S3 uploads with the AWS SDK. A CORS middleware wraps the three API routes and answers preflight requests.

Sign-up · SignUpFormDialog.js

Profile, headshot, resume

A dialog collects full name, student ID, email, graduation month and year, majors, minors or focuses, degree program and a short bio, plus a picture and a resume. Each file gets its own presigned URL and is uploaded to S3; the profile is then posted with the two file links.

Members · Carousel.js

Searchable carousel

Each card shows a member's headshot, name and bio, and opens the resume on click. Visitors move through it by swiping (50 px threshold), scrolling sideways (200 px), arrow keys or the on-screen arrows, with 0.5 s slides. A search box jumps to the first member whose name matches, and the jump waits in a queue if a slide is still moving.

Front page · HeroSection.js

Chapter sections

The hero line, EMPOWERING INNOVATION., resolves letter by letter out of random mathematical symbols (Unicode U+2200 to U+22D5), each position cycling three times before it settles. Below it sit About, Our Impact (Academic Recognition, Workshops and Weekly General Body Meetings, with a workshop video that plays on hover), Upcoming Events and the member carousel.

Deployment

  • The front end is a create-react-app build. deploy-frontend.sh builds it and syncs it to the S3 bucket for www.nsbeumbc.com, deleting files that are no longer in the build.
  • The Go server is compiled for Linux on amd64 and runs on AWS Elastic Beanstalk from a Procfile.
  • Member records live in MongoDB; headshots and resumes live in the nsbeheadshots S3 bucket under uploads/.
  • David's CV describes the whole setup as a Go backend on Elastic Beanstalk with a MongoDB/React stack and a continuous deployment pipeline.
